## Overview

E-ALL is a modern B2B electronics distribution platform developed for **FTG Global General Trading LLC**.

The platform enables businesses, retailers, and partners to explore global brands, discover products, and connect with E-ALL for distribution opportunities.

The project focuses on performance, responsive design, modern UI/UX, and long-term scalability.

---

## Project Goals

- Build a premium online presence for E-ALL.
- Showcase international brands.
- Present products professionally.
- Support B2B inquiries.
- Deliver excellent user experience.
- Maintain a scalable codebase.
